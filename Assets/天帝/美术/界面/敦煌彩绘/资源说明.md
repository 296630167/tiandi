# 敦煌彩绘 UI 与石庭背景

用户选定 D 概念：石青、矿物绿、赭橘、杏金，配暖绢纸、莲花与飞云。正文使用深青蓝；大面板外缘保留彩绘装饰，词条行使用均匀浅纸纹。主行动用青蓝底浅字，普通按钮用暖纸深字，品质色仅保留在短标签与细框。

本目录含39项成品：38个精灵和1张独立构筑图集。主页石庭、阅读背景、面板母版、按钮母版、槽位状态图集通过 Tap Maker「一滴水的故事」gpt 通道生成。原始资源及URL映射保留在指定Maker项目；提示词、映射与可重跑处理脚本位于项目 output/imagegen/敦煌彩绘正式。

主页背景的前景为连续平整石庭，中景栏杆明确分开可站立地面和远方云海。人物脚底锚点保持在设计坐标约(800,700)，独立软阴影放在(688,681,224,35)，包含双脚接触影。取消无动画时人物整体上下漂浮，实力卡下移以露出脚底地面；原主角动画与人物图片继续使用。
